---
title: "Claude Desktop"
description: "Connect FreightPOP to the Claude Desktop app from the connector directory."
---

FreightPOP is listed in the Claude connector directory. Claude Desktop shares your Claude.ai connectors, so connecting once covers both.

## Prerequisites

- Claude Desktop installed ([download](https://claude.ai/download))
- A Claude account on a paid plan (Pro, Max, Team, or Enterprise)
- An active FreightPOP account
- MCP access enabled for your user (ask your FreightPOP admin to turn on **AI Accessibility** for you and your company)

## Setup

<Steps>
  <Step title="Open the FreightPOP listing">
    <a href="https://claude.ai/directory/freightpopmcp" style={{ display: "inline-flex", alignItems: "center", gap: "8px", padding: "10px 20px", borderRadius: "8px", background: "#16A34A", color: "#FFFFFF", fontWeight: 600, fontSize: "15px", textDecoration: "none" }}>
  Add FreightPOP to Claude
</a>

    Or from inside the app: open **Settings → Connectors**, browse the directory, and search for **FreightPOP**.
  </Step>
  <Step title="Click Connect">
    Click **Connect** on the FreightPOP listing.
  </Step>
  <Step title="Sign in to FreightPOP">
    Claude opens a browser popup to the FreightPOP login page. Sign in with your normal credentials and approve the requested permissions.
  </Step>
  <Step title="Verify">
    Return to Claude Desktop. FreightPOP should show as **Connected**. Start a new chat and try a test prompt from [Getting Started](/getting-started).
  </Step>
</Steps>

## Adding it manually instead

If you need to point Claude at the server directly rather than use the directory listing, add it as a custom connector with this URL:

```text
https://tms-mcp.freightpop.com/mcp
```
