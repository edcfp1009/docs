The FreightPOP MCP Server exposes the following tools to your AI client. Tools are grouped by domain. Read-only tools are safe to run at any time. **Write tools** create real records or charges in your FreightPOP account — the AI client will always ask you to confirm before calling them.

## Read-only vs. write

| Type | Meaning | Confirmation required? |
| --- | --- | --- |
| **Read-only** | Retrieves data. Does not modify anything in FreightPOP. | No |
| **Write** | Creates or modifies records, or triggers billable actions. | **Yes** — the AI client asks before calling. |
